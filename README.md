# LiveContainer

无需越狱，直接在 iOS 设备上运行未签名应用。

## 简介

LiveContainer 是一款面向 iOS 设备的工具，让你在不越狱的前提下运行未签名的 IPA 应用。它通过容器化方式隔离每个应用，避免互相干扰，同时支持 AltStore、SideStore 等自签工具安装，适合开发调试、测试应用和日常使用。

## 功能

- 无需越狱即可运行未签名应用
- 每个应用独立容器，互不干扰
- 支持 AltStore、SideStore 等自签工具
- 支持后台运行与多任务切换
- 支持为应用单独开启 JIT
- 兼容 iOS 15 及以上系统

## 使用

1. 通过 AltStore 或 SideStore 安装 LiveContainer
2. 打开应用，按引导完成初始化
3. 导入要运行的 IPA 文件
4. 在应用列表中选择并启动
5. 如需 JIT，可在设置中单独开启
